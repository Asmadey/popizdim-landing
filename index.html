FAQ

Куда уходит мой голос?

Зависит от выбранной модели. Офлайн-модели (GigaAM, Parakeet, Whisper) обрабатывают звук на вашем Mac и ничего не отправляют. Облачные модели MAI отправляют звук поставщику: Azure Foundry или OpenRouter. Ключи хранятся только у вас в настройках.

Работает ли без интернета?

Да, с локальными моделями. Русский распознаёт GigaAM, английский Parakeet. Модель скачивается один раз, дальше интернет не нужен. Облачные модели и озвучка MAI-Voice интернет требуют.

Почему macOS предупреждает о неизвестном разработчике?

Сборка подписана без сертификата Apple Developer. Разрешите запуск в «Конфиденциальность и безопасность» → «Всё равно открыть» или выполните xattr -dr com.apple.quarantine "/Applications/Popizdim.app". Исходный код открыт, при желании приложение можно собрать самостоятельно.

Подойдёт ли Mac на Intel?

Готовый DMG собран только для Apple Silicon. Сборка из исходников на Intel не проверялась.

В каких приложениях это работает?

В любом, где есть поле ввода: почта, мессенджеры, заметки, браузер, терминал, редакторы. Для вставки текста нужен доступ «Универсальный доступ».

Это официальный продукт Microsoft?

Нет. Popizdim — неофициальный проект с открытым кодом. Он использует публичные модели Microsoft MAI через Azure Foundry и OpenRouter, не связан с Microsoft и не одобрен ею.
